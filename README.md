# Aplikasi E-Commerce PWB Anggun (CodeIgniter 3)

Aplikasi Web E-Commerce berbasis PHP (CodeIgniter 3) dengan fitur manajemen Master Data, Transaksi, dan Laporan.

## Fitur Utama
- **Autentikasi:** Login & Logout User Admin
- **Master Data:**
  - Manajemen Data Barang (Lihat, Tambah, Edit, Hapus)
  - Manajemen Data Pelanggan (Lihat, Hapus)
  - Manajemen Data Pemesan (Lihat, Tambah, Hapus)
  - Manajemen Data Ekspedisi
- **Transaksi:**
  - Lihat Pesanan
  - Lihat Pembayaran
- **Laporan:**
  - Cetak Laporan Penjualan

## Database
- File SQL: `pwb_anggun .sql`
- Tabel: `ada`, `barang`, `ekspedisi`, `order`, `pelanggan`, `pembayaran`, `pemesan`, `user`

## Persyaratan Sistem
- Web Server: Apache (WampServer / XAMPP)
- PHP: Versi 7.4 - 8.x
- DBMS: MySQL / MariaDB
